# Системный анализ · SA

[Главная](https://github.com/miha-mlv/SA-BA/tree/main) · **Системный анализ** · [Бизнес-анализ](https://github.com/miha-mlv/SA-BA/tree/BA)

Здесь будут кейсы по проектированию систем, работе с требованиями, данными и интеграциями.

## Кейсы

Завершённых кейсов пока нет. Для первого проекта подготовлен [шаблон](templates/case-template.md).

## Структура

- [cases/](cases/README.md) — отдельная папка для каждого проекта.
- [templates/case-template.md](templates/case-template.md) — шаблон описания системного кейса.

## Что показать в кейсе

| Артефакт | Что он объясняет |
| --- | --- |
| Контекст и границы системы | Пользователи, внешние системы, зона ответственности |
| Функциональные требования и сценарии | Какое поведение нужно реализовать |
| Нефункциональные требования | Измеримые ограничения по производительности, доступности и безопасности |
| API и интеграции | Контракты, ошибки, последовательность взаимодействий |
| Модель данных | Сущности, связи, ограничения целостности |
| Критерии приёмки | Как проверить выполнение требований |

Выбирай артефакты под задачу: необязательно включать все в каждый проект. Учебные допущения отмечай явно.
