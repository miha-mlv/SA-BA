# Бизнес-анализ · BA

[Главная](https://github.com/miha-mlv/SA-BA/tree/main) · [Системный анализ](https://github.com/miha-mlv/SA-BA/tree/SA) · **Бизнес-анализ**

Здесь будут кейсы по исследованию бизнес-проблем, анализу процессов и обоснованию изменений.

## Кейсы

Завершённых кейсов пока нет. Для первого проекта подготовлен [шаблон](templates/case-template.md).

## Структура

- [cases/](cases/README.md) — отдельная папка для каждого проекта.
- [templates/case-template.md](templates/case-template.md) — шаблон описания бизнес-кейса.

## Что показать в кейсе

| Артефакт | Что он объясняет |
| --- | --- |
| Описание проблемы и цели | Зачем бизнесу изменения |
| Анализ стейкхолдеров | Чьи интересы и ограничения нужно учитывать |
| План исследования и выводы | На каких данных основаны решения |
| AS-IS / TO-BE | Как работает процесс и что предлагается изменить |
| Бизнес-требования и правила | Какие результаты и ограничения важны |
| Оценка вариантов и метрики | Почему выбран подход и как оценить эффект |

Выбирай артефакты под задачу. Учебные интервью, расчёты и предположения помечай как моделирование.
