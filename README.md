# Михаил Малородов

Развиваюсь в системном и бизнес-анализе. Мой проектный опыт включает анализ предметной области, моделирование бизнес-процессов, формализацию требований и проектирование информационных систем. Техническая подготовка помогает мне прорабатывать взаимодействие клиента и сервера, API и модели данных.

В рамках учебных проектов занимался проектированием платформы для фермеров и покупателей, разработкой требований к системе поддержки строительных объектов, подготовкой технического задания на приложение задач и заметок, а также моделированием базы данных продуктового магазина.

Самостоятельно разработал PaymentGuard - учебный сервис предварительного контроля корпоративных платежей. Подготовил требования и бизнес-правила, BPMN/UML-диаграммы, API-контракты, модель данных, матрицу трассировки и локальный прототип.

Также самостоятельно подготовил техническое задание для отдела обучения компании ДРТ. Присутствовал на интервью с руководителем отдела при сборе требований. Этот проект дал мне опыт работы с потребностями реального заказчика и их описания в техническом задании.
