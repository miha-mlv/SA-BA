# Диаграммы PaymentGuard

## Страницы файла `PaymentGuard.drawio`

1. Контекст системы - акторы и внешние интеграции.
2. Компоненты - внутренние модули и целевой outbox publisher.
3. Состояния - жизненный цикл и допустимые переходы.
4. ERD - сущности и связи базы данных.
5. BPMN-процесс - проверка, оценка риска, решение и исполнение.
