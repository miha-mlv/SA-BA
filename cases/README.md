# Системные кейсы

Создай папку проекта, например `01-service-booking`, и скопируй в неё [шаблон](../templates/case-template.md) под именем `README.md`.

Рядом храни материалы проекта: `requirements.md`, `openapi.yaml`, `data-model.md`, папку `diagrams/`. Добавляй только необходимые файлы и связывай их ссылками из README кейса.

После подготовки добавь ссылку на кейс в корневой README ветки SA.
