# Бизнес-кейсы

Создай папку проекта, например `01-service-booking`, и скопируй в неё [шаблон](../templates/case-template.md) под именем `README.md`.

Рядом храни материалы проекта: `stakeholders.md`, `business-requirements.md`, `metrics.md`, папку `processes/` с моделями AS-IS и TO-BE. Добавляй только необходимые файлы и связывай их ссылками из README кейса.

После подготовки добавь ссылку на кейс в корневой README ветки BA. Один учебный проект можно раскрыть с двух сторон: бизнес-анализ в BA и системное решение в SA.
