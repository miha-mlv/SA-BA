# Диаграммы FarmerApp

## Структура каталога

- `as-is/` - исходная IDEF0-модель существующего процесса поиска и приобретения фермерской продукции.
- `to-be/` - IDEF0-модель целевого процесса после внедрения FarmerApp
- `architecture/` - архитектурная диаграмма системы.
- `data/` - ERD и редактируемая модель MySQL Workbench.
- `use-cases/` - подготовленная диаграмма вариантов использования.
